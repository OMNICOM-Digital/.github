## What we're building

**[GLPI MCP Server Plugin](https://OMNICOM-Digital.github.io/#projects)** — a GLPI plugin that exposes GLPI as an MCP (Model Context Protocol) server, so AI assistants like Microsoft Copilot and Claude can work directly with tickets, the knowledge base, users, groups, and the service catalog — through a standard tool interface instead of one-off custom integrations per client.

Alongside it, we publish the internal tooling we lean on day to day: GLPI notification templates, service catalog icon sets, and backup/ops scripts for production GLPI environments.

See **[OMNICOM-Digital.github.io](https://OMNICOM-Digital.github.io)** for the full write-up on each project.
